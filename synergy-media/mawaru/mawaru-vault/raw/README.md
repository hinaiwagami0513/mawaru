# raw/ は書き換えない

拾ったものを**そのまま**置く場所。議事録・Figmaエクスポート・実装ログ・バージョン履歴など、読み取り専用の一次情報。

## なぜ触らないか
同じAIが同じノートを読んでは書き換えを繰り返すと、細部がボヤけて誤りが積み上がる。
raw を ground truth として固定し、その上で entities / concepts を賢く育てる。

## ルール
- AIは raw を編集しない。整理結果は entities / concepts に書く。
- entities / concepts の各ページは**どの raw から来たか**をリンクで示す（裏取り）。
- ソースリンクの無い主張は「要確認」扱いにして信用しない。
