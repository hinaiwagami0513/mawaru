# template-feature（テンプレ機能・TSX化済）

> 「毎回この型で」要望（イオン九州発）への回答。視覚的に選択+チャットで詳細修正。

## 一覧（v2採択・横長コンパクト3列）
- カード: アイコン48px + テンプレ名 + 作成者アバター + 使用回数 + 更新日 + 種別バッジ + ⭐。高さ約64px。
- アイコン=絵文字+背景色セット（Notionページアイコン的な識別子）。
- フィルター(すべて/動画/画像/お気入)+検索+並替+グリッド/リスト切替。

## 作成（チャットベース・2カラム）
左（参考素材+テンプレ要素リアルタイム）+ 右（AIチャット）。
テンプレ要素7項目: 構図/色合い/雰囲気/演者の見せ方/テロップスタイル/BGM・効果音/商品登場。
3状態視覚化: done(緑✓)/editing(オレンジ●)/todo(半透明○)+「3/7確定」バッジ。
動画モード=9:16 / 画像モード=1:1。

## 作成フロー5画面
一覧→タイプ選択→参考素材アップ(PC/ドライブ)→チャット作成→アイコン+名前設定→保存。
確定3要件: アイコン(絵文字/画像2タブ) / アスペクト比(9:16 or 1:1) / 作成者表示。公開範囲=自分のみ/チーム。
