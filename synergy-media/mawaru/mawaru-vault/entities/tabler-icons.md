# tabler-icons（唯一のアイコン系）

> UIのアイコンは全て Tabler(`ti-*`)。絵文字はUIに使わない（🦊マスコット意匠は例外）。

## 実装
- 実プロダクト(Next+shadcn)は npm `@tabler/icons-react`。
- 配布用スタンドアロンHTMLは woff2 ごと埋め込む（CDN直リンク禁止＝再現性が壊れる）。

## SNSブランドアイコン（[[state-color-plus-glyph]] とセット）
`ti-brand-instagram` / `ti-brand-x` / `ti-brand-tiktok` / `ti-brand-youtube`。
媒体は色だけで区別しない、必ずアイコンを添える。
※旧仕様の絵文字SNSバッジ(📷✕🎵▶)は失効 → [[superseded]]。
