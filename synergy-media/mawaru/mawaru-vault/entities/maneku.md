# maneku（マネク / MANEKU — 姉妹サービス）

> コメント → DMで自動クーポン → 店で使われた数＝来店数。マワルが続けさせた投稿を、来店に変える2本目。

## 位置づけ
- マワル（[[brand-mawaru]]）の**姉妹サービス**。別プロダクトだが同じ型で並べる。
- 意味は「**招く**」。売っているものは「**客が来た数が見える**」。
- マワルが「運用が止まらない」を売り、マネクが「続いた先の成果」を受ける。2本あることで成果まで面倒を見られる。

## 仕組み（4ステップ）
1. **投稿が続く** — マワルが止めない
2. **コメントが付く** — クーポン目当てで増える
3. **DMでクーポン** — 取得から利用まで自動
4. **店で使われる** — その数がそのまま来店数になる

投稿にコメントが付くと、DMでクーポンが自動で届く。そのクーポンが店で使われた数が、そのまま来店数になる。

## サポーター経由の送客
同じ**マワルサポーター**が、自分のフォロワーにクーポンを配って送客することもできる。
→ サポーターは「教える人」であると同時に「送客する人」になれる（[[selling-the-unstopped-state]]）。
