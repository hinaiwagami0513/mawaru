## ★タブ分割を廃止・1つのドライブに統合（8/21確定）

**「素材」/「AI読み取り資料」の2タブをやめる。** 何でもアップロードできる Google ドライブのような入れ物にして、
画像・動画・音声（=素材）と PDF・Office・URL（=資料）を**同じ一覧に混ぜる**。分けるのは入れる時ではなく**使う時**。

- 会議での合意 — 佐藤「入れるところは一緒で…この中に全部入れられるって感じにしたい」/ 岩上「PDF とかも全部突っ込んじゃって、素材を持ってくる時はもう画像だけ選択できるみたいな感じ」。
- **採用するデザインは素材タブ側**（ツリー + カードグリッド）。資料カードをそこに混ぜる。
- 性格の違いは**置き場所ではなく、右の詳細パネルのアクション**で出す:

| ファイルの種類 | 詳細パネルに出るもの |
|---|---|
| 素材（画像/動画/音声） | `[この素材で投稿を作る]` + **使用済み投稿の逆引き** |
| 資料（PDF/Office/URL） | AIの読み込み状態 + `[この資料をもとに投稿を作る]` + `[もう一度読み込む]`（失敗・読み込み中のみ）。逆引きは出さない |

- 一覧のフィルタチップに **`資料・URL`** を追加。ツリーに **`資料・リンク`** を追加。カードのサムネに読み込み状態バッジ（済み/中/失敗）。
- ヘッダーの `[URLを追加]` を素材の `[アップロード]` と並べる。
- 混ざるぶん、**使われ方の違いは冒頭のATTENTIONで言い切る**（素材は投稿に貼れる / 資料はAIが読むだけで貼られない）。旧タブの説明文が担っていた役目をここが引き継ぐ。
- 既存の `drive_wire.html#learn` リンク（設定画面・画面一覧）は**「資料・URL」で絞った状態**で開くよう維持。
- 反映済み: `mawaru_board/drive_wire.html`。文言連動は `settings_wire.html` / `flow_image_material_wire.html` / `flow_video_material_wire.html` / `board.html` / `screen_viewer_wire.html`。
