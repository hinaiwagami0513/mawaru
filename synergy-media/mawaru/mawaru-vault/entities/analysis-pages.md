> 3タブ（ビジュアル/アカウント/投稿レポート）+ 掘り下げ2画面。共通のアカウントヘッダーを全画面で持つ。

## ⚠️ 名称の経緯
上部タブは **「分析レポート」→「アカウントレポート」** に改名済み。
raw/ の議事録にこの改名の記録は無い（6本全文確認済み）ので、口頭決定と思われる。
raw は書き換え禁止なので、7/17・7/31 の議事録には旧名「分析レポート」が残っている。読むとき注意。
なお同じ画面をヘルプでは「AIレポート」とも呼んでおり、呼称が2つある状態は未解決。

## 期間表示はページ上部に集約する
「いつのレポートか」は**上部のレポート期間ヘッダー1箇所で言い切る**。カード側に散らさない。
- `2026年7月のレポート` + **今月/先月/◯ヶ月前バッジ** + 実日付レンジ（`2026/07/01 - 07/31`、末日は自動計算）。
- 月送りは前へ/次への2ボタン。未来は無いので今月では「次へ」を非活性。
- ⚠️ 8枚のカード画像（`assets/vr-01〜08.png`）には「今月の主要指標」等が焼き込まれている。
  上部で月を明示したので画像側の「今月の」は重複。**次の画像再生成時に外す**。
  外すまでは、先月に切り替えても画像だけ「今月の」と言い続ける不整合が残る。

## 投稿レポートの指標は各投稿にも出す（2026-08-30）
**プロフィール率 / シェア数 / インタラクション / リーチしたアカウント数** は、全体（`.ms-card`）にだけ
並んでいて**各投稿には無かった**。陽菜「全体ではなくて各投稿です」。全体側は残したまま各投稿に足した。

| 面 | 状態 |
|---|---|
| 全体（`.ms-card`） | 前から4つとも有り。そのまま |
| 詳細シート（`.spm` / `.ssm`） | 前から4つとも有り（リーチしたアカウント数・シェア・インタラクション・プロフィール率） |
| **一覧カード（`.post-quick-stats`）** | 表示・いいね・コメントの**3つだけだった** → **主役3つに入れ替え**（下記） |

### 一覧は3つ、シートは8つ（2026-08-30 確定）
一度8つ全部を一覧カードに並べたが、陽菜「この見えパターンもなんかギツギツすぎない？」。
**一覧＝見比べる場所 / 詳細シート＝詳しく見る場所**で切り分ける。

| 面 | 出すもの |
|---|---|
| 一覧カード | **リーチ / 反応（インタラクション）/ プロフィール率** の3つ |
| 詳細シート | 8つとも（見られた2 + 反応の合計と内訳4 + 率4） |

残す3つは「届いた数」「反応の合計」「フォローの入口」。
いいね / コメント / 保存 / シェア / 表示 は押した先で見る。
⚠️ **シェア数は一覧から消える**（陽菜が承知のうえで選択）。
見た目は詳細シートの `.smm` と揃える（同じ数字が画面ごとに違う顔をしない）。
⚠️ 一覧だけラベルが「反応」で、全体・シートは「インタラクション」。呼び分けが1つ増えている。

- **カードの数値は `posts` から描く**（`fillQuickStats()`）。もとは HTML 直書きで、しかも目のアイコンに
  リーチ(127)を入れており、詳細シート（目=表示203 / 人=リーチ127）と食い違っていた。
  同じ元データから描けば、片方だけ直して数字がずれることがなくなる。
- 実装 `analysis_posts_wire.html`。

### 詳細シートの指標はメリハリを付ける（2026-08-30）
7つを同じ大きさ・同じ色で4列に並べていたので、どれが主役か分からなかった。
陽菜「もっとメリハリ欲しいかな」。**全体タブと同じ語彙で2組に分け、大きさで差を付けた。**

| 組 | 中身 | 大きさ |
|---|---|---|
| 見られた | リーチ / 表示 | 28px（この投稿の主役） |
| 反応された | インタラクション（合計） | 21px |
| 〃 の内訳 | いいね / コメント / 保存 / シェア | 本文サイズ |

- **メリハリは大きさと組で作る（色ではなく）。数字はオレンジ。**
  一度 `foreground` にしたが陽菜「数字はオレンジの方が良かったかも」で戻した（2026-08-30）。
  もとから `.spm-val.hi` でオレンジにしていた（今月のベストの1件だけ）ので、全件オレンジに揃えた形。
  以前オレンジが問題だったのは「7つが同じ大きさで全部オレンジ」だったからで、
  大きさが3段に分かれた今は色が揃っていても主役は埋もれない。
  ⚠️ グラフ面と同じく [[orange-only-interaction]] の例外にあたる。押せる合図は形で担保する。
- インタラクションは いいね+コメント+保存+シェア の合計。内訳の上に置くと計算が見える。
- 4列グリッドをやめたので、**「リーチしたアカウント数」が2行に折れる問題と、
  7指標で最後の1マスが余る問題（空セルで埋めていた）が両方消えた。**

## 投稿詳細シートに 改善点 / 分析概要 / コンテンツ を入れる（2026-08-30）
旧UI（投稿データ画面の右下）にあった4つ組 `改善点 / 分析概要 / コンテンツ / 出力` を、
新UIの**投稿詳細シートの中**に入れる（陽菜依頼）。
旧版は番号付きの長文が縦に積まれた文章の壁だったので、そのまま移さず作り直した。

| タブ | 何を出すか | 形 |
|---|---|---|
| 改善点 | 次にやること | 番号 + 見出し + **「いま → こうする」の差分チップ** + 説明 |
| 分析概要 | この投稿がどうだったか | バッジ + 一文（既存の `analysis` をそのまま使う） |
| コンテンツ | 中身の内訳 | 形式 / 画像枚数 / 本文の文字数 / ハッシュタグ数 + キャプション実物 |

- **差分チップが肝。** 「ハッシュタグを5個から12〜15個に増やしましょう」と文で書くと読み飛ばされる。
  `5個 → 12〜15個` だけ抜いてチップにすると、何をどうするかが一目で分かる。
- **コンテンツの数字は `caption` から数える**（`improve` のようにデータで持たない）。
  二重に持つと、文面を直したときに数字だけ古いまま残る。
- 出力はタブに混ぜずボタン（上記の「出力はタブではなくボタン」と同じ扱い）。
  出すのは開いている投稿なので、ダイアログに日付を出して取り違えを防ぐ。
- ⚠️ 分析概要のペインに `.sheet-analysis-list` を直接付けない。
  その `display:flex` が `.an-pane{display:none}` に後勝ちして、切り替えても出しっぱなしになる。
  中に `.an-ov` を入れ子で置く（実際そうなっていた）。
- 実装 `analysis_posts_wire.html`（`.an-tabs` / `.im` / `.cn-grid` / `anTab()` / `#dlgOut`）。

## 出力はタブではなくボタン（2026-08-30）
AIレポートのサブタブが `改善点 / 分析概要 / コンテンツ / 出力` の4つで、**出力だけタブだった**。
陽菜「出力っていうページが欲しいんじゃなくて、出力ボタンが欲しい。そのタブ切り替えごとに。
出力ボタンを押した後にPDFなのか何なのかって選べるダイアログの方がいい」。

- タブに混ぜると、改善点・分析概要・コンテンツと横並びの**「読む中身」**に見える。
  出力は読むものではなく、**どのタブを見ていても押せる操作**。
- サブタブは3つに戻し、**更新日時の隣に「出力」ボタン**を置いた（`.hd-right`）。
- 中身（画像で保存 / PDFでまとめる / テキストでコピー）は**押したあとのダイアログ**へ。
  3つから1つ選ぶので `alertDialog`（sonner）は使えない（実行ボタンが1つしかない）。
  `settings_wire` と同じ `.dlgov` / `.dlg` の形をそのまま持ってくる（[[component-procurement]]）。
- **ダイアログはタブを見ている**。「〇〇 を出します」と出し、PNGの枚数もそのタブのスライド数にする
  （改善点5枚 / 分析概要4枚 / コンテンツ8枚）。押してから驚かせない。
- 出力タブが無くなったので、`activateTab` の「スライドを持たないタブでは矢印とドットを隠す」分岐は
  実際には通らなくなった（防御として残置）。
- 実装 `analysis_report_wire.html`（`.btn-out` / `#dlgOut` / `openOut()`）。

## ⚠️ このCSSの罠
`analysis_visual_wire.html` は `.vr-*` の基本ルールが `@media` ブロックより**後ろ**にある。
同一詳細度は後勝ちなので、レスポンシブ指定を上の `@media` に書くと効かない。
実際 `.vr-slide-grid` のSP1列指定が長らく効かず、スマホで2列のままだった。
**`.vr-*` のSP指定は基本ルールの直後に置く**こと。`.acct-*` は基本ルールが先なので上の `@media` でよい。

## 共通アカウントヘッダー（`.acct-hd`）
全6画面が同じ構造。アイコン + アカウント名 + ハンドル + 統計pill + 切替ドロップダウン。
`.acct-row` は nowrap のままだとSPで縮み、「アリスト」が1文字ずつ折れる。
SPで `flex-wrap: wrap` + 名前/ハンドル/統計に `white-space: nowrap` を当てて解決済み（全6画面）。
