# dev-environment（開発・実行の約束事）

> ビルド実行と成果物出力の定型。作業のたびに迷わないための固定手順。

- Node実行: `NODE_PATH=/home/claude/.npm-global/lib/node_modules node build_script.js`
- pip: `pip install --break-system-packages`
- 成果物: `/mnt/user-data/outputs/` に置いて present_files で共有。
- Volta管理Node（[[hina]]環境）はフルパス指定が要る場面あり。

## git は必ずパス明示

`~/dev` が公開リポジトリ `mawaru` の git ルート。SHIP など別グループが同じ作業ツリーに同居しているので
`git add -A` は使わない。**push = 公開配信**。詳細と守り方は [[ship-separation]]。

## ★PRベースの共同開発（8/21確定）

マワル 本体は **React**。実装の分担がワイヤー納品からプルリクエストに変わった。

1. **佐藤がベースコードを作る**（新規ページ・重い実装はここ）。
2. **陽菜がそのリポジトリを Claude Code で直す** — デザイン反映・細かい修正。
3. **プルリクを送り、佐藤が確認してマージ**。

- 目的は伝達コストの削減。岩上「1個ずつ伝えるとちょっと時間かかる」/ 佐藤「細かい修正をやってもらえて僕はチェックだけでいいっていう意味では助かる」。
- 佐藤のレビュー観点は「リクエストの時点でコードちゃんとしてるか」。
- **開始条件**: 新しい画面のコードが一通り出来上がってから。それまでは従来どおりワイヤーHTMLで先行する。
- **反映の優先順位**: 投稿作成フロー → 分析 → 他画面を逐次。前2つだけ先にメイン環境へ入れる。
- 佐藤側で受け入れ体制（レビュー・マージのワークフロー）を整備中。

### 自動実行の作り（8/28夕方に作り直した）

会議では「23時に書かれる / 23時前に落としたら次に開いた時に書かれる」と説明したが、
**後半は実際には動いていなかった**。macOS の `StartCalendarInterval` は、その時刻に
**電源が入っていない日は取り返さない**（スリープなら起きた時に走るが、シャットダウンは走らない）。
毎晩20〜21時に落としていたため 8/25〜8/28 が丸ごと欠けていた（`launchctl print` の `runs=0` で確認）。

いまは LaunchAgent 2本立て。

| ジョブ | 発火 | やること |
|---|---|---|
| `jp.shipinc.mawaru.worklog` | 毎日 23:00 | その日ぶんを書く |
| `jp.shipinc.mawaru.worklog.catchup` | **ログイン時**（`RunAtLoad`） | `--backfill`。md に無い過去の日を古い順に埋める |

- 下限は `BACKFILL_FLOOR=2026-08-22`（自動化の初日）。それ以前は掘り返さない。
- **昨日ぶんだけは md にあっても1回書き直す**。23時より前に一度書いた日が途中の状態で固まるため。
  1日1回に抑える印は `~/Library/Logs/.mawaru-worklog-refreshed`。
  ⚠️ 手で書いた日を上書きさせたくないときは、この印にその日付を先に入れておく。
- 素材が無い日は `collect-worklog.sh` が `<!-- WORKLOG:NO-MATERIAL -->` を出して打ち切る（休んだ日は載らない）。
- `insert-worklog.py` は**日付降順の正しい位置**に差し込む。以前は常に先頭に入れる作りで、
  バックフィルで順番が壊れた（8/26 → 8/25 → 8/27 になった）。
- md もシートも**同じ日は差し替え**。何度流し直しても行は増えない。

### スプレッドシート側の作り

`log` タブがデータ本体（`worklog-to-sheet.py` が Apps Script の doPost に投げる先）。
`view` タブは **B1 に入れた日付を `log` から FILTER で引くだけの表**。B1 は手打ちで、
触らない限り同じ日を出し続ける。「シートが動いていない」と見えるのはたいていこれ。
最新日を自動で拾う式にはしない（**特定の日を指定して見たい**ため・8/28 陽菜判断）。

関連: pptx等の別スキルの陽菜指定ルールは横断ルール（このvaultの範囲外だが [[cursor]] 併記）。
