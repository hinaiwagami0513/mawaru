# brand-rename-pending（名前は確定、色はまだ。半分だけ解除）

> 8/28: サービス名とメインカラーが変わる可能性があるため、名前と色に縛られる制作物を止めていた。
> **9/8: 名前は「マワル」に確定**（[[brand-mawaru]]）。**メインカラーは依然未確定**。ペンディングは半分だけ解ける。

## いまの状態

| | 8/28時点 | 9/8時点 |
|---|---|---|
| サービス名称 | ❓未確定 | ✅ **マワル（MAWARU）** / ドメイン mawaru-sns.jp |
| メインカラー | ❓未確定 | ❓**未確定のまま**。9/8スライドは色に触れていない |

⚠️ スライドが紺地なのは SYNERGY MEDIA の**社内資料テンプレの色**。プロダクトのメインカラーを決めたものではない。
DESIGN.md の primary（オレンジ `#fe7235`）は引き続き現行値として扱う（[[design-tokens]]）。

## だから止めるもの / 動かせるもの

| | 判断 | 理由 |
|---|---|---|
| キャラクター（🦊）の作り直し | **着手可**（色は後で乗せる） | 名前が確定したので「お腹の文字」問題は解ける。**現行の狐は作り直し確定** |
| ロゴ制作 | **着手可**（配色は保留） | 形・字面は「マワル / MAWARU」で決まった。色だけ最後に差す |
| サービスサイトの構成・制作 | **構成は着手可 / 配色は保留** | 名前とコピー（「全店、止まらない。だから、伸びる。」）が決まった。[[service-website]] |
| 本体UIの色 | **止めない** | DESIGN.md の primary / secondary を差し替えるだけで通る |
| 本体UIの機能・スマホ対応 | **止めない**（最優先） | ブランドと独立。8/28の最優先事項のまま |

## 色替えが安いのはトークン設計のおかげ
岩上「デザインMDでプライマリーを変えるだけなので」「UIの方はマジですぐ色変えられると思ってます」。
DESIGN.md → globals.css の一方向生成で、色がセマンティック名に閉じているから成立する（[[design-tokens]]）。
**この前提を崩す作り方（生の16進をワイヤーに直書きする等）をしない**。

## 完全解除の合図
佐藤から**メインカラーの確定連絡**が来たら残りが解ける。着手順は ロゴ → キャラクター → サービスサイト。
