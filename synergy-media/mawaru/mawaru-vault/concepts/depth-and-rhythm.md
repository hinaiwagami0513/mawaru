# depth-and-rhythm（面の高さと余白のリズム）

> 「AIっぽく単調」の正体は色ではなく**形の均質さ**。影・角丸・余白・グリッドを一律にしないこと。

## 教訓
ホーム画面の監査（[[raw/design-audit-2026-08-19-home]]）で、12個のコンテナが
**純白・1px枠・16px角丸・影なし・22px間隔**で全部同じだった。どこを見ればいいかの手がかりが画面に無い。
DESIGN.md に書いてある仕様が**実装で落ちていただけ**で、新しい判断は1つも要らなかった。

## 守ること

**影は3段を実際に使う。** `--shadow-card` / `--shadow-raised` / `--shadow-overlay`。
「常時影」と書いてあるものが `box-shadow:none` になっていないか、実測で確かめる。
カードは常時 `card`、ホバーで `raised` に上げる。

**角丸は大小で分ける。** 小カード（KPI・ミニカード）= `md`(12) / 大きい面 = `lg`(16)。
全部同じにすると、大小の区別が形からも消える。

**余白はリズムを作る。** セクション**間** 32px / セクション**内** 16px。
4pxグリッドから外れた値（22px 等）を置かない。全部同値だと「どこで話が変わるか」が読めない。

**等幅グリッドを避ける。** 3枚並び・4枚並びを `repeat(N,1fr)` で割らない。
**中身の量と重要度で幅を変える**（ToDo は行数が多いので広く、KPI は一番見せたい1枚を広く）。
アイコン＋太字見出し＋説明の同型カードが等間隔で反復するのが、いちばん「AIが作った画面」に見える形。

**主役とラベルの声量を変える。** ページの主役（あいさつ）とセクション見出しが同じ 20px/700 だった。
主役は `h1`(30px/900) 以上へ。900 は 30px 以上専用（[[design-tokens]]）。

**当たり判定は44px。** 「もっと見る」等のテキストリンクは実測18pxだった。
見た目を変えずに `padding` で44pxを作り、負の `margin` で詰め戻す。
