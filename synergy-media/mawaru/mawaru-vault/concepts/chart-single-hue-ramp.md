# chart-single-hue-ramp（グラフは単一色相ランプ）

> グラフの色は `chart-1..5` からしか取らない。**primary（オレンジ）起点**の1色相を濃淡で並べる。意味色は流用しない。

## 教訓
ホーム「今月の作業時間」のドーナツが 青(info) / ピンク(like) / 紫(#9c6bd8) の3色相だった。
**紫はパレットに無い値**で、赤とピンクは状態バッジと同じ意味を持つ色。
「このカラーは使用されてないので使用されている色に変更する」の指摘（2026-08-18）を受けて作り直した。

一度 info（青）のランプで組んだが、**青は他所で面として使われておらず画面から浮く**ため却下。
**オレンジに確定**（2026-08-19 陽菜判断）。

### 8/21 に青へ戻され、同日オレンジに再確定
2026-08-21 のパレット刷新で secondary に青（`#0077ff`）が入り、DESIGN.md が一度
「secondary を据えたので例外は不要」として**青ランプに書き換えられた**。
が、同日に陽菜が「オレンジに変更」と指示したため**オレンジで再確定**。
青ランプ（`#0058c4 / #0077ff / #00a0ff / #00c3ff / #8fe4ff`）は失効。
同じ論点が2回ひっくり返っているので、**次に青を提案する前にこの節を読む**。

## 決めたこと
- **`chart-1..5` は DESIGN.md が源泉**。新パレット版は
  `#fe7235`(=primary) → `#fea735`(=primary-light) → `#febb6b` → `#fdd0a0` → `#fde4d6`。
  chart-3 / chart-4 は chart-2 と chart-5 の間を等分した中間色（新パレットに対応する段が無いため作った）。
  旧パレット版（`#ef6108` 〜 `#fff2e2`）は失効。
- **1つの量の内訳は色相を分けない。多い系列ほど濃い。** 順位がそのまま読める上に、明度差なので色覚特性があっても追える。
- **意味色（success / warning / like）を系列色に流用しない。** 緑＝好調・赤＝いいね の意味が人名やカテゴリに漏れる。
- **系列が5を超えたら円グラフをやめる**（横棒＋「その他」）。ランプが破綻する。

## ⚠️ グラフは [[orange-only-interaction]] の唯一の例外
オレンジは本来「押せる/選ばれてる/進む先」専用。グラフだけこの例外に入る。**青に戻さない。**
押せないことは色ではなく形で担保する:
- グラフ面に **枠・影・`cursor:pointer` を付けない**。
- ボタン/チップは今までどおり **オレンジ枠 or 塗り + ラベル**。面だけのグラフとは読み分く。

## 色以外の手がかりを必ず3つ持たせる
1. 円の外に系列名を直置き。2. 凡例に実数と割合。3. 凡例の下に構成比バー。
ランプは隣り合う段が近いので、色だけで読ませない（[[state-color-plus-glyph]] と同じ考え方）。

### 引き出し線は引かない（2026-08-19 試作のうえ不採用）
スライスから細線を伸ばして名前に繋ぐ案を実装したが、**円のまわりに線が増えて盤面が重くなる**ため戻した。
3系列くらいなら中心角の外側に名字を直置きすれば結び先は分かる。同じ案を再提案しない。

## 端は丸める
ドーナツは `stroke-linecap: round`。角丸スケール（8/12/16/20）と手触りを揃える。
凡例のスウォッチも丸ドットにする。
⚠️ 丸いキャップは **太さの半分ずつ両端に飛び出す**ので、`dasharray` から「すき間 + 太さ」を引き、
`dashoffset` を「太さの半分 + すき間の半分」ぶん進めないと隣とくっついてすき間が消える。

## ツールチップは浮かせず円の中心に差し込む
ドーナツ幅が296pxしかないので、浮くカードは合計か隣のスライスを必ず隠す。
**中心（元から空き）を「合計」→「ホバー中の人の内訳」に差し替える**。
円と凡例はホバー連動：どちらに触れても 該当スライスが太くなる / 他が落ちる / 凡例行が浮く。

実装: `mawaru_board/shell_header_sidebar_wire.html`（`.db-work` / `.wk-*`、shadcn の ChartContainer・
ChartTooltip・ChartLegend にそのまま写せる構造）。React化では `chartConfig` の color に `var(--chart-N)` を渡す。
